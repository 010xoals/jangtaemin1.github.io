기준일: 2026년 10월 16일 · RE:SONG 음악 커뮤니티 시범 운영

운영 안내

회원 기능의 공개 운영을 위한 초기 안내입니다. 운영 문의처를 등록했으며 Google 로그인을 통한 회원 기능을 단계적으로 공개하고 있습니다. 정책과 기능은 운영하면서 보완할 수 있습니다. 중요한 개인정보를 공개 GitHub 게시판에 올리지 마세요.

1. 처리하는 정보

Google 로그인 사용 시 Supabase 인증 서버에 Google 계정 식별자, 이메일 등 인증에 필요한 정보가 처리됩니다. RE:SONG 공개 프로필에는 회원 UUID, 별도 닉네임(초기값 ‘음악 친구’)이 저장됩니다. 사용자가 제출한 음악별 평점(1~5), 리뷰 본문, 작성·수정 시각을 저장합니다. Google 계정의 실명을 공개 닉네임으로 자동 설정하지 않습니다.

2. 이용 목적

로그인 인증, 본인의 평가 저장·수정·삭제, 사용자 간 평점 집계·리뷰 표시, 문의 및 부정 이용 대응에 이용합니다. 정보의 광고 타겟팅 활용 기능은 현재 연결되어 있지 않습니다.

3. 보관·삭제

회원으로 활동하는 동안 정보를 보관하며, 본인 탈퇴 기능으로 계정과 연결된 공개 프로필·평점·리뷰를 삭제할 수 있도록 설계했습니다. 서비스 제공사의 운영 기록 및 백업 보존 기간은 해당 업체 정책이 적용될 수 있습니다.

4. 외부 서비스

인증 및 데이터베이스는 Supabase(서울 리전)를 이용하고 Google OAuth를 로그인 수단으로 사용합니다. GitHub Pages는 사이트 배포에, YouTube는 사용자가 선택한 음악의 동영상 재생에 사용합니다. YouTube 재생 시 Google/YouTube의 별도 개인정보 처리 정책이 적용됩니다. 외부 서비스의 네트워크·운영 위치는 변경될 수 있습니다.

5. 사용자의 권리

로그인한 회원은 닉네임, 자신의 리뷰와 평점을 직접 수정할 수 있습니다. 회원 탈퇴 기능을 통해 본인 데이터를 삭제할 수 있으며, Google 계정에서 RE:SONG 앱에 부여한 권한을 별도로 철회할 수도 있습니다.

6. 보안

평점·리뷰 쓰기 작업은 사용자 인증 및 데이터베이스의 행 단위 접근 제어 정책을 사용합니다. 서비스 운영용 비밀 API 키는 웹페이지에 포함하지 않습니다. 보안이 모든 위험을 완전히 제거하는 것은 아닙니다.
